# 📊 Data Jobs Dashboard – Power BI

![Data job dashboard](/images/Data_job_dashboard.png)

## 📝 Project Overview
This project presents an interactive Power BI dashboard built using real-world **Data jobs from 2024** , covering roles such as Data Analyst, Data Scientist, Data Engineer, and related tech positions.  
The goal of this dashboard is to uncover meaningful insights about the **job market**, including hiring trends, salary ranges, job types, work-from-home availability, and global job distribution.

The report includes:
- A **summary dashboard** with KPIs, salary insights, job trends, and category-wise breakdown.
- A **drill-through page** providing job-title-specific analytics such as yearly/hourly salary, job platforms, benefits, and global distribution.

This dashboard helps **Job seekers, Job Transitioners and Job Swappers** quickly explore job market conditions and compare roles across the data domain — in a simple, visual, and interactive way.

## 📚 Dataset Description

This dashboard is powered by a rich dataset of **tech job postings from 2020–2024**, covering roles like Data Analyst, Data Scientist, and Software Engineer across multiple countries 🌍.

The dataset brings together:
- 🏢 **Job listings from global hiring platforms**
- 💼 **Role details** like schedules, remote availability, required skills  
- 💰 **Compensation insights** (hourly + yearly)
- 🎓 **Job requirements** such as degree mentions & benefits  
- 📅 **Time-based posting patterns** across four years

Overall, it provides a **complete picture of modern data job trends**, helping uncover insights about demand, salary patterns, and skill expectations in today’s tech landscape 🚀.

## 🧠 How to Use the Dashboard

This dashboard is designed to be **simple, interactive, and intuitive** 😎.

Here’s how to explore it:

- 🟦 **Select specific Job title** to filter by job title, schedule, platform, or location.  
- 🔄 **Drill through** to job-specific pages for deeper salary & benefit insights. Note-**Press ctrl while clicking Drill through button**   
- 📍 **Hover over visuals** to see tooltips with extra details.  
- 🌍 **Explore the map** to identify global job hotspots.  
- 📊 **Compare Yearly vs Hourly salary** using the KPI cards and gauges.

Every chart is interactive — click, filter, explore, repeat.

## 🛠️ Power BI Features & Tech Used

A lot of behind-the-scenes magic powers this dashboard ✨:

### 🔢 Core Engine
- 📐 **DAX Measures** for KPIs like median salary, job count, platform ratios, WFH %, year-over-year change  
- 🗂️ **Data Modeling** to connect job details, salaries, locations & benefits  
- 🎨 **Custom Themes** for a clean and modern look  

### 📊 Visuals Used
- 🍩 **Donut Charts** – job category share, benefits share, platform distribution  
- 🎯 **Gauge Charts** – salary expectations, rating metrics  
- 🌳 **Treemaps** – skill categories & job volume comparisons  
- 📊 **Bar & Column Charts** – job trends, salary comparisons, platform counts  
- 📈 **Line Charts** – trend over time (yearly salary & job posting timeline)  
- 🔵 **Scatter Charts** – salary vs job type relationships  
- 🌍 **Map Visuals** – global job distribution  
- 📛 **KPI Cards** – quick metrics like total jobs, median salary & star rating  

### 🧭 Interactivity
- 🔗 **Drill-Through Pages** for job-specific analytics  
- 🎛️ **Dynamic Slicers** (job title, platform, location, schedule, remote flag)  
- 📝 **Tooltips** with extra information on hover  
- 🔄 **Cross-filtering** between all visuals  

Together, these features create an **interactive, fast, and insight-rich** analytical experience 🔥.
